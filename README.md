# Snack

一个支持排行榜的贪吃蛇游戏，用于练习企业级全栈开发流程。

## 项目介绍

Snack 是一个前后端分离的贪吃蛇游戏项目。玩家可以在浏览器中控制蛇移动、吃食物、累计分数，
游戏结束后分数上传至后端，并展示历史最高分与排行榜。

本项目的核心目标不是"做一个贪吃蛇"，而是**完整走一遍企业级项目的开发流程**：
需求立项、文档先行、规范约束、分支协作、代码审查、持续集成、部署上线。

## 功能特性

### 已规划（MVP）
- [ ] 单机贪吃蛇：移动、吃食物、计分、游戏结束判定
- [ ] 分数上传至后端
- [ ] 展示历史最高分
- [ ] 排行榜（Top 10）

### 后续规划
- [ ] 玩家昵称
- [ ] 多人在线对战
- [ ] 移动端适配

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue3 + TypeScript + Vite |
| 后端 | Java + Spring Boot |
| 数据库 | MySQL |
| 构建 | Vite（前端）/ Maven（后端） |
| 版本控制 | Git + GitHub |

## 环境要求

| 工具 | 版本 | 说明 |
|---|---|---|
| Node.js | 24.x | 前端构建 |
| npm | 11.x | 随 Node 安装 |
| JDK | 21 (LTS) | 后端编译运行 |
| Maven | 3.9.x | 后端构建 |
| MySQL | 8.0.x | 数据库 |
| Git | 2.40 或更高 | 版本控制 |

> ⚠️ 版本一致性：为避免"本地能跑、别人不能跑"，项目将使用
> `.nvmrc`（前端）、Maven Wrapper（后端）、`docker-compose.yml`（数据库）
> 锁定具体版本。详见各子目录。
